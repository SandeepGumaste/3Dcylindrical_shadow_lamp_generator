# Guided UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (inline, the owner's choice).

**Goal:** Ask first-time visitors whether they are a beginner; beginners get the Guided steps design for Tealight shade mode, everyone else gets today's UI. Both share one controller.

**Architecture:** Pure logic in `src/ui/` (the remembered answer, the step and setting configuration, how a change applies), a `Guided*` component set with its own scoped CSS and light/dark theme, and a small wiring change in `App.tsx`. `useTealightGenerator` and every Tealight geometry/worker file stay unchanged.

**Tech Stack:** React 19, TypeScript, Tailwind 4 (existing UI), plain scoped CSS for the guided view, Vitest.

**Design source:** the Guided steps prototype (`docs/prototypes/guided-steps.html` on branch `docs/guided-steps-prototype`) and the owner's approval in conversation.

## Global Constraints
- Existing UI unchanged except: a welcome overlay on first visit and one small "Switch to guided steps" button. No edits to `useTealightGenerator.ts`, Tealight geometry or workers, `TealightPanel.tsx`, `TealightViewport.tsx`, `TableInset.tsx`.
- Both views use the same controller, so settings survive switching; generation rules stay: generate on first load and when the image changes, settings changes only show the out-of-date banner.
- The answer is remembered per device (localStorage, every access in try/catch, works without it). Question text: "Are you new to making lamps like this?" with "Yes, guide me" and "No, show me everything".
- Guided view: four clickable steps (Pick an image, Shape the shade, Make it printable, Generate and export), Back and Next, light and dark theme with a toggle (system default, remembered), phone layout with the preview pinned on top. Resolution in step 3, the light (flame or LED) in step 2.
- Every Tealight setting appears in exactly one step. Box shadow mode is not part of this work.

## Review Focus
- localStorage unavailable or throwing: the app still works and asks every visit.
- Switching Guided/Advanced mid-work keeps settings, the generated model and the out-of-date state.
- Editing the rib count in Guided turns the optimizer off, closing the bottom clears vents, turning the optimizer off keeps the current rib count.
- A settings error (for example a flame height above the shade) is visible in every step and blocks Generate.
- Phone width: no horizontal scroll, Back/Next reachable, preview pinned.
